В первом задании я работала с приложением для заказа еды Lunch Tray. Мне нужно было связать готовые экраны между собой. Для этого я создала перечисление со всеми экранами, добавила контроллер навигации и настроила NavHost. Также я сделала верхнюю панель, которая показывает название текущего экрана и кнопку «Назад» в виде стрелочки (она появляется везде, кроме самого первого экрана). Еще я прописала логику для кнопок «Отмена» и «Отправить»: при их нажатии заказ очищается, а приложение возвращает пользователя на самый первый экран, полностью очищая историю переходов.
